# Tower Defense research (Kingdom Rush & peers) — Oct 2026

## Why Kingdom Rush works
- **4 clearly distinct tower roles** (archers = fast/unarmored, mages = anti-armor magic, artillery = AoE ground, barracks = melee blockers). Limited build spots turn every map into a puzzle (MobyGames, AV Club).
- **Barracks / blocking** is the signature mechanic: soldiers physically stop fast enemies -> kill zones; rally point micro (Game Developer "campaign level design").
- **Branching tier-4 upgrades** (two specializations each with own abilities) = the "real strategy" layer.
- **Hero + 2 spells** (meteor/rain of fire + reinforcements) give active agency between builds.
- **Early wave call** for bonus gold/cooldown = risk/reward pacing control; wave preview of incoming enemy types.
- **Enemy variety** (~30 types: fast, armored, magic-resistant, flying, healers, spawners) teaches counters gradually; one new mechanic per level.
- Charming hand-drawn art, readable silhouettes, bosses with personality, almost no RNG ("failures are strategy, not dice").
- Stars (1-3) per level + Heroic/Iron challenges + meta upgrade tree spent with stars.

## Peers
- **Bloons TD 6**: the replayability king — endless/free play, daily/weekly events, bosses, many tower path combos. Complaints: grind, steep difficulty spikes, unclear tower stats, clunky mobile UI.
- **KR Vengeance/Alliance**: tower/hero experimentation, DLC stages. Complaints: slow campaign, "lazy wave compositions", poor balance, no endless mode, heroes/reinforcements so strong barracks feel pointless, paywalled heroes/towers.
- **Iron Marines / Legends of KR**: hero-centric, more RTS/RPG; shows players like controllable units but core TD gets diluted.
- **Plants vs Zombies**: super readable, one-tap placement, humour, each level introduces exactly one new thing.
- **Arknights**: operator blocking counts + deploy-anywhere, deep but complex; Element TD: element combos & mazing.

## Common complaints to avoid
1. Campaign too short / best upgrades unlocked too late -> unlock all 4 families early, branches from level 1.
2. No endless mode / little reason to replay -> Endless + Challenge (Iron Oath) per level, stars and meta tree.
3. Unclear what abilities do -> two-tap confirm with description panel for every build/upgrade/branch.
4. Hero/spells overpowering towers -> modest hero, spells with cooldowns; towers still required (verified by sim).
5. Difficulty spikes, boring waves -> generated waves mixing 1-3 enemy types, gradual unlocks, bosses with mechanics.
6. Paywalls / forced ads -> only optional rewarded ads (gems, second-chance wave retry, double reward).

## Design takeaways for our game ("Oasis Guardians / حُرّاس الواحة")
Arabian-nights setting (oasis city, djinn, sand worms, ifrit), 4 families x 3 levels + 2 branches + mastery, hero Princess Nour with 2 abilities, Falling Star + Call to Arms spells, wave preview flag w/ early-call bonus, 12 levels / 3 regions (Golden Dunes, Palm River, Moon Citadel at night with dynamic lighting), endless + challenge, star-powered meta tree, juicy feedback (sparks, shake, numbers, death anims, trails, glow).
